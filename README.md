# 班费公示平台

这是一个基于 Supabase 云数据库的班级班费公开工具，支持多角色权限、流水记账、删除审批、学期管理、反馈系统等功能。

> **当前状态**：内测中 · 欢迎反馈问题与改进建议


## ✨ 功能特性

- **浏览模式**：无需登录，全班同学均可快速查看实时班费流水
- **多角色管理**：总管理员 / 生活委员 / 班委
- **记账功能**：记录收支、金额、经手人，支持多学期切换
- **删除审批流程**：生活委员/班委申请删除 → 总管理员审批
- **多学期支持**：独立统计各学期收支，支持余额结转
- **数据导出**：一键导出 HTML 格式账单，双击即可查看
- **操作日志**：记录所有关键操作，便于追溯
- **反馈系统**：访客及登录用户均可提交反馈，支持匿名；总管理员可确认已读、公开回复或删除反馈；班委/生活委员可查看自己的反馈状态


## 🎨 UI 设计特点

- **微交互动效**：首页入口卡片悬停上浮并带有柔和发光，页面切换有淡入升起动画
- **胶囊形昼夜切换**：小巧圆润的昼夜切换滑块，适配移动端窄屏
- **暖色纸面质感**：延续米白背景与暖橙/蓝/黄的配色体系


## 🔧 技术栈

- 前端：HTML + 内嵌 CSS + JavaScript
- 数据库：Supabase (PostgreSQL)
- 部署：GitHub Pages / Cloudflare Pages

## 🔒 安全说明

本项目使用 Supabase 的 `anon public key` 进行 API 访问，该密钥设计上即供前端使用。真正的数据安全依赖于 Supabase 的 RLS 策略，目前正在逐步完善中。当前已做的安全加固措施包括：

- 账号密码不再全量加载至前端内存
- 登录时按学号单独查询并校验密码
- 客户端登录失败次数限制（5 次后锁定 30 秒）
- 图片加载 XSS 防护
