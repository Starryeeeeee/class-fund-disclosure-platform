#  班费公示平台

一个基于 Supabase 云数据库的班级班费管理工具，支持多角色权限、流水记账、删除审批、学期管理等功能。

> **当前版本**：内测阶段 · 欢迎反馈问题与改进建议


## ✨ 主要功能

- **浏览模式**：无需登录，全班同学可查看实时班费流水
- **多角色管理**：总管理员 / 生活委员 / 班委 / 访客，各司其职
- **记账功能**：记录收支、金额、经手人，支持多学期切换
- **删除审批流程**：生活委员/班委申请删除 → 总管理员审批
- **多学期支持**：独立统计各学期收支，支持结转
- **数据导出**：一键导出 HTML 格式账单，双击即可查看
- **操作日志**：记录所有关键操作，便于追溯


## ⚠️ 当前版本说明（内测阶段）

### 已实现功能
- 云端数据实时同步（Supabase）
- 多角色权限控制（总管理员 / 生活委员 / 班委 / 访客）
- 流水增删改查 + 学期切换
- 删除申请 + 审批流程
- 操作日志 + 访问日志
- HTML 格式数据导出

### 已知待完善/未开放功能
- **发票/收据上传功能**：代码框架已预留，因存储容量与性能考虑暂未开放，后续视需求决定是否启用
- **安全防护**：当前为基础权限校验，未启用 RLS 等高级安全策略
- **密码修改**：目前由管理员统一管理账号，暂不支持用户自助修改密码

如果您在使用过程中发现任何 **Bug**，或有 **功能建议**，欢迎在 Issues 中提出，或联系班级管理员。

## 📖 使用说明

| 身份 | 操作 |
|------|------|
| **访客** | 直接点击「浏览模式」查看流水 |
| **总管理员** | 点击「管理员登录」进行记账、审批、管理后台 |
| **生活委员 / 班委** | 登录后新增记录、申请删除 |
| **默认测试账号** | 总管理员：20 / 密码 10601 |
