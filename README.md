# 班费公示平台

一个基于 Supabase 云数据库的班级班费管理工具，支持多角色权限、流水记账、删除审批、学期管理等功能。

> **当前状态**：内测中 · 欢迎反馈问题与改进建议


## ✨ 功能特性

- **浏览模式**：无需登录，全班同学均可查看实时班费流水
- **多角色管理**：总管理员 / 生活委员 / 班委 / 访客，各司其职
- **记账功能**：记录收支、金额、经手人，支持多学期切换
- **删除审批流程**：生活委员/班委申请删除 → 总管理员审批
- **多学期支持**：独立统计各学期收支，支持余额结转
- **数据导出**：一键导出 HTML 格式账单，双击即可查看
- **操作日志**：记录所有关键操作，便于追溯


## 🔧 技术栈

- 前端：HTML + 内嵌CSS + JavaScript（最终仅由HTML实现全部功能）
- 数据库：Supabase (PostgreSQL)
- 部署：GitHub Pages / Cloudflare Pages

| 身份 | 操作 |

## 🔒 安全说明

本项目使用 Supabase 的 `anon public key` 进行 API 访问，该密钥设计上即供前端使用。真正的数据安全依赖于 Supabase 的 RLS 策略，目前正在逐步完善中。当前已做的安全加固措施包括：

- 账号密码不再全量加载至前端内存
- 登录时按学号单独查询并校验密码
- 客户端登录失败次数限制（5 次后锁定 30 秒）
- 图片加载 XSS 防护
