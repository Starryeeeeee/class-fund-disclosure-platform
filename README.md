# Class Fund Disclosure Platform 班费公示平台

这是一个基于 Supabase 云数据库的班级班费公开工具，支持多角色权限、流水记账、删除审批、学期管理、反馈系统等功能。

> **当前状态**：内测中 · 欢迎反馈问题与改进建议  
> **当前版本**：v3.3.0（2026年9月30日）

## ✨ 功能特性

- **浏览模式**：无需登录，全班同学均可快速查看实时班费流水
- **多角色管理**：总管理员 / 生活委员 / 普通同学（访客）
- **记账功能**：记录收支、金额、经手人，支持多学期切换
- **发票 / 收据上传**：可选上传图片凭证，客户端自动压缩（最长边 1200px、质量 0.72、原图 5MB 上限），点击流水可直接查看
- **删除审批流程**：生活委员申请删除 → 总管理员审批
- **多学期支持**：独立统计各学期收支，支持余额结转
- **数据导出**：一键导出 HTML / Markdown / PDF 三种格式账单
- **操作日志**：记录所有关键操作，便于追溯；管理员可清除 30 天前日志或按需多选删除
- **反馈系统**：登录用户可提交反馈，支持匿名；总管理员可确认已读、公开回复或删除反馈；普通同学可查看自己的反馈状态
- **静默同步**：30 秒轮询 + 页面可见性触发，数据变更自动刷新

## 🔐 安全架构（本次重大升级）

- **Supabase Auth 登录**：不再在前端比对明文密码，所有登录走 Supabase Auth，密码哈希存储
- **行级安全策略（RLS）**：数据库层面强制权限隔离，访客只能读取公开数据，写操作严格按角色放行
- **防提权触发器**：普通用户无法自行修改 role / student_id 等敏感字段，杜绝越权提权
- **会话保持**：刷新页面自动恢复登录状态，无需重复输入密码
- **用户自助改密**：登录后可在设置中修改密码，无需管理员介入

- **莫奈色系主题**：6 套低饱和配色（暖橙 / 青绿 / 雾蓝 / 藕紫 / 陶土 / 墨绿），实时预览、一键切换
- **更新字体**：阿里汉仪智能体（AliHYAiHei-Beta）用于导航标题、文件夹标签、弹窗标题等

- **卡片圆角可调**：小 / 中 / 大三档切换
- **动效开关**：一键开启或关闭全部过渡动画
- **胶囊形昼夜切换**：自绘 SVG 滑块
- **纸面质感组件**：便利贴公告、文件夹卡片、铅笔箭头分隔符
- **悬浮工具栏**：左下角 FAB，含信箱与设置入口

## 🛠️ 技术栈

- 前端：HTML + 内嵌 CSS + JavaScript（单文件 SPA）
- 数据库：Supabase (PostgreSQL + PostgREST)
- 认证：Supabase Auth
- 字体：Google Fonts（Inter / Source Serif 4）+ 阿里汉仪智能体 AliHYAiHei-Beta
- 部署：GitHub Pages / Cloudflare Pages

## 📖 使用说明

| 身份 | 操作 |
|------|------|
| **访客** | 点击「以访客身份访问」查看流水，可浏览公开反馈 |
| **总管理员** | 登录后进行记账、审批、管理后台、回复与删除反馈、日志管理 |
| **生活委员** | 登录后新增记录、申请删除，查看自己的反馈状态 |
| **普通同学** | 登录后查看流水、提交反馈、修改个人昵称与密码 |

> **初始密码**：所有账号初始密码均为 **123456** ，登录后可在设置中修改。
