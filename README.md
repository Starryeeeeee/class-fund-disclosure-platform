# 高二(1)班 班费公示平台

一个基于 Supabase 云数据库的班级班费管理工具，支持多角色权限、流水记账、删除审批、学期管理等功能。

## 主要功能

- **浏览模式**：无需登录，全班同学可查看实时班费流水
- **多角色管理**：总管理员 / 生活委员 / 班委 / 访客，各司其职
- **记账功能**：记录收支、金额、经手人，支持发票上传
- **删除审批流程**：普通管理员申请删除，总管理员审批
- **多学期切换**：支持多个学期独立统计
- **数据导出**：一键导出 HTML 格式账单，双击即可查看

## 技术栈

- 前端：纯 HTML + CSS + JavaScript
- 数据库：Supabase (PostgreSQL)
- 部署：GitHub Pages / Cloudflare Pages

## 使用说明

1. **访客**：直接点击“浏览模式”查看流水
2. **管理员**：点击“管理员登录”进行记账和管理
3. **默认账号**：总管理员 20 / 密码 10601

## 数据安全

所有数据实时同步至云端，支持一键导出备份。
