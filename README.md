# Class Fund Disclosure Platform
# 班费公示平台

这是一个基于 Supabase 云数据库的班级班费公开工具，支持多角色权限、流水记账、删除审批、学期管理、反馈系统等功能。

> **当前状态**：内测中 · 欢迎反馈问题与改进建议


## ✨ 功能特性

- **浏览模式**：无需登录，全班同学均可快速查看实时班费流水
- **多角色管理**：总管理员 / 生活委员 / 班委
- **记账功能**：记录收支、金额、经手人，支持多学期切换
- **发票 / 收据上传**：可选上传图片凭证，客户端自动压缩（最长边 1200px、质量 0.72、原图 5MB 上限），点击流水可直接查看
- **删除审批流程**：生活委员/班委申请删除 → 总管理员审批
- **多学期支持**：独立统计各学期收支，支持余额结转
- **数据导出**：一键导出 HTML / Markdown / PDF 三种格式账单
- **操作日志**：记录所有关键操作，便于追溯
- **反馈系统**：访客及登录用户均可提交反馈，支持匿名；总管理员可确认已读、公开回复或删除反馈；班委/生活委员可查看自己的反馈状态
- **静默同步**：30 秒轮询 + 页面可见性触发，数据变更自动刷新


## 🎨 UI 设计特点

- **莫奈色系主题**：6 套低饱和配色（暖橙 / 青绿 / 雾蓝 / 藕紫 / 陶土 / 墨绿），实时预览、一键切换，影响文件夹卡片、主按钮、色板标签等
- **更新字体**：阿里汉仪智能体（AliHYAiHei-Beta）用于导航标题、文件夹标签、弹窗标题、关于页班级名、登录页「欢迎回来」
- **苹果风 Toast**：全圆角、毛玻璃、缩放淡出，替换传统左侧竖线样式
- **卡片圆角可调**：小 / 中 / 大三档切换
- **动效开关**：一键开启或关闭全部过渡动画
- **胶囊形昼夜切换**：自绘 SVG 滑块，适配移动端窄屏
- **纸面质感组件**：便利贴公告（带胶带、折边、纸张纹理）、文件夹卡片（彩色标签 + 色条）、铅笔箭头分隔符
- **微交互**：印章动画、按钮叠加阴影按压反馈、页面切换淡入升起、数字滚动
- **悬浮工具栏**：左下角 FAB，进入主页后显示，含信箱与设置入口
- **返回顶部**：右下角悬浮按钮，滚动 320px 后出现


## 🔧 技术栈

- 前端：HTML + 内嵌 CSS + JavaScript（单文件 SPA）
- 数据库：Supabase (PostgreSQL + PostgREST)
- 字体：Google Fonts（Inter / Source Serif 4）+ 阿里汉仪智能体AliHYAiHei-Beta（依托cn-font-split 工具分包）
- 构建工具：Node.js + cn-font-split
- 部署：GitHub Pages / Cloudflare Pages

## 🔒 安全说明

本项目使用 Supabase 的 `anon public key` 进行 API 访问，该密钥设计上即供前端使用。真正的数据安全依赖于 Supabase 的 RLS 策略，目前正在逐步完善中。当前已做的安全加固措施包括：

- 账号列表接口不返回密码字段，密码仅在登录时按学号单独查询
- 客户端登录失败次数限制（5 次后锁定 30 秒）
- 图片源白名单校验（`safeImgSrc`），阻断 `javascript:` 等伪协议
- 所有用户输入渲染前经 `esc()` 转义
- 客户端输入长度与金额上限校验
- 发票图片上传前客户端压缩，限制体积与尺寸
